# Channel hashtags

Every post on [@arbhub_site](https://t.me/arbhub_site) carries tags. Telegram
indexes them per channel, so a reader who taps `#GoldRewards` gets every gold
post in order and nothing else — which is the only navigation a channel has.
A tag set only works if it is small and used the same way every time; a
vocabulary that grows post by post indexes nothing.

## Always, on every post

```
#ArbiSmart #Polygon #USDT
```

Three tags identify the project and the chain. `#ArbiSmart` is also what makes
an impersonating channel visibly different from this one — copies rarely tag
consistently.

## Then one or two topic tags

| Tag | Use for |
| --- | --- |
| `#StartHere` | The pinned explainer. One post only, ever. |
| `#Update` | A change to the site or the contract went live. |
| `#Transparency` | Publishing something unflattering: a correction, a limitation, a figure that does not help us. |
| `#GoldRewards` `#Gold` | The physical gold programme. |
| `#Referral` | The three-level referral system, team volume, tiers. |
| `#Staking` | Plans, rates, terms, claiming, early exit. |
| `#Security` | The security model, audits, verification, bug bounty. |
| `#Scam` | Warnings about impersonators. Deliberately blunt — the tag itself is the message when it appears in a preview. |
| `#HowTo` | Step-by-step guides: funding, depositing, connecting. |
| `#DeFi` | Broad reach. Add only where it is genuinely apt. |

## Rules

Three to six tags in total. Beyond that they stop being navigation and start
looking like reach-farming, which is exactly the register this project is
trying not to be read in.

Tags go at the very bottom, after a blank line. Never inside a sentence.

English only, matching the channel.

Never invent one for a single post. If a subject is worth a tag it is worth
adding to the table above first.

## Language

**Every post is written in English.** The tag line already said "English only,
matching the channel", which assumed a channel language that was never written
down — and posts went out in Persian on that ambiguity. So it is stated here
plainly: body text, headings and captions are English, on every post, without
being asked each time.

Persian material still exists and still gets shared — the full guide is a
Persian PDF and is linked from the channel. A translated document sent as an
attachment is a different thing from the channel's own voice, and only the
second one is fixed to English.

## Placement note

A photo caption caps at 1024 characters and a text post at 4096. When the body
runs past a caption limit, post the image with a short tagged caption and the
full text as a reply — do not truncate to fit the tags in, and do not drop the
tags to fit the text.
