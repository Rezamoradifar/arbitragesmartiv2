# arbitragesmartiv2

داشبورد **فقط‌خواندنی (read-only)** برای قرارداد هوشمند ArbiSmart روی شبکه‌ی Polygon.

آدرس قرارداد: [`0xdE8859444957B327F18f75E2C600d6Cc275Ea662`](https://polygonscan.com/address/0xdE8859444957B327F18f75E2C600d6Cc275Ea662)

## ⚠️ هشدار

این قرارداد سود روزانه‌ی ثابت (تا ۳٪ در روز) و سیستم رفرال چندسطحی دارد که از نظر
ساختاری شبیه طرح‌های Ponzi/HYIP است. تابع `polymarketArbitrageTrade` به مالک قرارداد
اجازه می‌دهد هر زمان تا ۲۰٪ از موجودی USDT قرارداد را برداشت کند، بدون هیچ اثبات
آن‌چین بابت بازگشت سود. این داشبورد صرفاً برای **شفافیت و مشاهده‌ی داده** ساخته شده و
هیچ دکمه‌ی واریز/برداشت/استیک ندارد. قبل از تعامل مالی با این قرارداد، آن را مستقل
بررسی/حسابرسی کنید.

## این پروژه چه‌کار می‌کند

- تمام داده‌ها را مستقیم و فقط از طریق فراخوانی توابع `view` قرارداد (روی RPC عمومی
  Polygon) می‌خواند.
- آمار کلی: تعداد کاربران، مجموع استیک، مجموع پرداختی، موجودی قرارداد، وضعیت
  pause/emergency، سقف برداشت «آربیتراژ» owner.
- جدول پلن‌ها، نرخ روزانه و نرخ‌های رفرال.
- جست‌وجوی وضعیت هر آدرس دلخواه (مبلغ استیک، پاداش در انتظار، اطلاعات رفرال و...).
- **هیچ تراکنش نوشتنی ارسال نمی‌کند** — نه stake، نه claim، نه topUp.
